# Module 06 — Advanced Patterns

This module is the deep end. It assumes you've shipped at least one working app or agent and you want to move from "I can build things" to "I run a small AI production system."

It's actively being written. Topics that will land in the next few weeks:

- **Skills and slash commands** — package your repeated workflows as reusable Claude Code commands
- **Context management** — how to keep agents reliable when the conversation gets long
- **The gstack workflow** — Garry Tan's 20+ agent production engineering pipeline, adapted for executive operators
- **Multi-agent orchestration** — research → draft → review → ship, with one orchestrator coordinating specialists
- **Production deployment patterns** — observability, cost management, security, scaling agents from "works on my laptop" to "serves my whole team"
- **Going from build to product** — when something you built crosses the line from internal tool to sellable product, what changes
