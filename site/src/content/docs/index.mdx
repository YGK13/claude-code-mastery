<section class="ccm-section" data-reveal>
  <span class="ccm-kicker">What this is</span>
  <h2>A working path through Claude Code, not a link dump</h2>
  <p class="ccm-definition"><strong>Claude Code Mastery</strong> is a free curriculum for learning Claude Code, the terminal-based agentic coding tool from Anthropic that reads, writes and runs code in your project when you describe what you want. Six modules take you from installation to shipped web apps, Python AI agents, hook-driven automations and your own MCP server. Written by Yuri Kruman, published by PortLev, updated September 2026. Independent of Anthropic.</p>
</section>

<section class="ccm-section" data-reveal>
  <span class="ccm-kicker">Who it is for</span>
  <h2>Two audiences, one curriculum, two entry points</h2>
  <p class="ccm-lede">Executives who need working tools without a dev team, and builders who want to stop typing boilerplate. The lessons are the same; the order and the examples differ.</p>
  <div class="ccm-split">
    <article>
      <h3>Executives, operators and consultants</h3>
      <p>You bill by the hour, you can read code well enough to follow it and you have 5 to 20 hours a week of repetitive work you would delegate if you had an engineer.</p>
      <ul>
        <li>Module 01 assumes zero terminal experience and goes slowly</li>
        <li>Examples: KPI dashboard, billable-hours tracker, client intake bot, board-prep research agent</li>
        <li>Every module ends with something deployed you can show on Monday</li>
      </ul>
      <a class="ccm-path-link" href="/curriculum/01-getting-started/overview/">Start at Module 01 →</a>
    </article>
    <article>
      <h3>Builders and developers</h3>
      <p>You already ship software and want the patterns that make an agentic workflow reliable: CLAUDE.md conventions, hooks, permissions, multi-agent orchestration and MCP.</p>
      <ul>
        <li>Skim Module 01 for CLAUDE.md and permissions, then jump ahead</li>
        <li>Module 03 builds tool-using agents on the Claude API in Python</li>
        <li>Modules 04 to 06 cover hooks, CI/CD, custom MCP servers, skills and context management</li>
      </ul>
      <a class="ccm-path-link" href="/curriculum/03-ai-agents/overview/">Start at Module 03 →</a>
    </article>
  </div>

<section class="ccm-section" data-reveal>
  <span class="ccm-kicker">Start here</span>
  <h2>Your first two hours</h2>
  <p class="ccm-lede">Module 01 is deliberately short. By the end of it you have a working install, one real prompt shipped and a single-file app open in your browser.</p>
  <ol class="ccm-steps">
    <li>
      <h3>Install and authenticate</h3>
      <p>Node.js 20+, then <code>npm install -g @anthropic-ai/claude-code</code> and an API key or Claude subscription. Mac, Windows and Linux, step by step. <a href="/curriculum/01-getting-started/installation/">Installation →</a></p>
    </li>
    <li>
      <h3>Ship one thing in 60 seconds</h3>
      <p>Open a folder, type <code>claude</code>, paste the weekly-status prompt from the lesson. A copy-paste-ready Monday status generator appears in your browser. <a href="/curriculum/01-getting-started/first-session/">Your first session →</a></p>
    </li>
    <li>
      <h3>Set the rules, then pick your track</h3>
      <p>Write a CLAUDE.md so the agent follows your conventions, lock down permissions, then go to Module 02 (web apps) or Module 03 (agents). <a href="/curriculum/01-getting-started/claude-md-guide/">The CLAUDE.md file →</a></p>
    </li>
  </ol>
</section>

  <span class="ccm-kicker">Outcomes</span>
  <h2>What you will have built</h2>
  <ul class="ccm-outcomes">
    <li><strong>A standalone HTML app</strong>React from a CDN, no build tools. Open the file and it runs. Module 02.</li>
    <li><strong>A Next.js app on Vercel</strong>Full-stack, deployed to a public URL, ready for auth and a database. Module 02.</li>
    <li><strong>A Python AI agent</strong>Claude as the reasoning engine, your functions as tools. Module 03.</li>
    <li><strong>An automated workflow</strong>Hooks that fire on file writes and commits, agents that run in parallel, CI in GitHub Actions. Module 04.</li>
    <li><strong>A custom MCP server</strong>Your own data exposed to Claude in any session. Module 05.</li>
    <li><strong>A production-ready AI feature</strong>Skills, context management and a full engineering workflow. Module 06.</li>
