This is an editorial list, not a link dump. Every item is here because Yuri or a cohort member found it genuinely useful and explained why.

## Foundational reading on Claude Code

- **[Claude Code official docs](https://code.claude.com/docs)** - Anthropic's source of truth. Always check here first when something looks different from this curriculum. The platform moves fast.
- **[Claude API docs](https://platform.claude.com/docs)** - The API the agents in Module 03 are built on. Reference material, not a tutorial.
- **[Anthropic's prompting guide](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview)** - The single most leveraged skill in this whole stack. Read it once a quarter.

## AI agents

- **[Building Effective Agents (Anthropic)](https://www.anthropic.com/research/building-effective-agents)** - Anthropic's own framework for when to use a workflow vs. an agent. Required reading before Module 03.
- **[MCP (Model Context Protocol)](https://modelcontextprotocol.io)** - The spec that makes Module 05 possible. Skim, don't memorize.

## Thinking about AI as a business operator

- **[The AI Wage Gap](https://aiwagegap.com)** - Yuri's ongoing work on what AI does to mid-career compensation. Frames *why* you're building, not just *how*.
- **[Every - How I AI](https://every.to/p/how-i-ai)** - Senior operators sharing real workflows, not theoretical frameworks.

## Newsletters worth the inbox space

- **[Latent Space](https://www.latent.space/)** - Engineering-adjacent AI news. Skim weekly.
- **[Stratechery](https://stratechery.com/)** - Ben Thompson's strategy lens. Best macro context on AI as a business shift.
- **[One Useful Thing](https://www.oneusefulthing.org/)** - Ethan Mollick. The least hyped, most actionable AI writing in academia.
