# Claude Code Mastery: site audit, September 2026

Property: https://claude-code-mastery-self.vercel.app (Vercel project `claude-code-mastery`, git-linked to `YGK13/claude-code-mastery`, branch `master`, no custom domain).
Stack: Astro 6 + Starlight 0.39, static output from `site/dist`. Content in `site/src/content/docs`, mirrored from `modules/` and `reference/`.
Audited 2026-09-02 by fetching the live homepage, a lesson page and a 404 probe through the Vercel fetch tool, plus a full read of the repo.

## 0. What this host actually serves (verified 2026-09-03)

A sibling audit fetched https://claude-code-mastery-self.vercel.app live and found an Astro site titled "PortLev Learn" that canonicalises every URL to `https://learn.portlev.com/`, with a banner reading "Founding Cohort · 4 / 8 spots left" and "$2,500 (next cohort $4,500)". The question was whether that legacy content lives in this repo or in a different project. Answer, from the repo itself:

- `vercel.json` at the repo root: `buildCommand: cd site && npm install && npm run build`, `outputDirectory: site/dist`, `framework: null`. The Vercel project `claude-code-mastery` builds this repo's `site/` and nothing else.
- `master:site/astro.config.mjs` (commit 21ff901, the current production deploy): `site: 'https://learn.portlev.com'`, `title: 'PortLev Learn'`, `Banner: './src/components/CohortBanner.astro'`. `master:site/src/components/CohortBanner.astro` line 16 and 18 contain the exact strings "Founding Cohort · 4 / 8 spots left" and "$2,500 (next cohort $4,500)".
- So the legacy content is this repo's own `master` branch. It is not served from the separate `/home/user/portlev-learn` clone (`YGK13/portlev-learn`, an Astro fork that targets `https://program.portlev.com`, has no domain and is listed in the inventory as legacy tooling; untouched by this rebuild).
- learn.portlev.com itself is a different product on a different repo and stack (`learn-portlev`, Next.js, PortLev Academy). It does not host this curriculum. A 308 from this host to learn.portlev.com would send visitors to a site that has none of the 37 pages here and would orphan the GitHub README, Code Wiki and Leverage Brief links that already point to this host.

Why `master` looks like that: the site was first scaffolded in May 2026 as the "PortLev Learn" front end for the founding cohort and pointed at the domain that was planned at the time; the domain was never attached to this project, learn.portlev.com went live on the Next.js app instead, and this host kept declaring itself a duplicate of a site it is not.

**Recommendation: this host becomes the Claude Code Mastery course site.** That is what this branch does: canonical, sitemap, OG and JSON-LD all on this host; "PortLev Learn" removed; the cohort banner and its hard-coded spot count and prices deleted; the cohort page links to learn.portlev.com for current pricing instead of stating numbers. Do not add a redirect to learn.portlev.com. Next, attach a real domain (section 5 and `docs/GTM-2026-09.md` section 10: `code.portlev.com` recommended, `agenticcode.school` and `codewithagents.dev` as purchasable alternatives), then let Vercel 308 the `.vercel.app` host to it.

## 2. Message-market fit issues

- The page sold a cohort, not the curriculum. For an unknown domain with zero authority the free curriculum is the acquisition asset; the cohort is the monetisation asset. The order was inverted.
- Two audiences (executives and builders) were collapsed into one; developers were told "This is not Claude Code 101 for developers", which turns away the audience most likely to star, fork and share the repo.
- No "what is this" sentence for answer engines. No FAQ. No entity block linking Yuri Kruman to PortLev to the site.
- Trademark exposure: the site is titled after an Anthropic product with no independence statement.

## 4. Pass 2 review (2026-09-05)

An adversarial re-review of the branch, with the built site served locally and driven in a real browser. Nine defects found, all fixed on this branch.

| Sev | Where | Defect | Fix |
|-----|-------|--------|-----|
| P0 | 16 lesson pages | Every lesson's closing "Next:" link still pointed at a relative `.md` file (`./first-session.md`, `../03-ai-agents/README.md`). The sync script rewrites links only on pages it generates, and these pages already existed, so the primary in-lesson navigation 404'd on all 16. | `sync-content.mjs` now always repairs `.md` links on existing pages (a `relinked` pass) without touching anything else. The `modules/` sources keep their `.md` links so they still read correctly on GitHub. |
| P1 | Whole landing page | `[data-reveal]` sections were `opacity: 0` and revealed only by an IntersectionObserver, so with scripting off - and in print, link previews and any crawler that does not run scripts - roughly 80% of the homepage rendered blank. | The hidden state is now scoped to `.js-reveal`, a class set synchronously in `<head>` only when scripting is on. Verified: 25 reveal blocks, 0 invisible, with JavaScript disabled. |
| P1 | Every landing-page grid | Starlight's `* + *` rule inside `.sl-markdown-content` added a top margin to every grid child after the first, so each card sat 4 to 16 px lower than its neighbour (most visible on the two pricing cards and the two audience cards). | One reset rule: spacing in these containers comes from `gap` alone. Both pricing cards now share a top edge and a height. |
| P1 | `/cohort` | The callout was raw HTML wrapping markdown, which CommonMark does not parse, so the page rendered a literal `**Executive AI Cohort.**` and a bare `[text](url)` instead of a link to the programs page. | Blank lines inside the `<div>` so the markdown is parsed. |
| P1 | Site-wide copy | 504 em dashes across pages, modules, reference, templates and examples, against the house rule. | Swept: 350 normalised to a spaced hyphen in prose, 154 swapped 1:1 inside code blocks and inline code so column alignment in the sample `CLAUDE.md` files survives. |
| P1 | Homepage `<title>` | 62 characters, over the 60 limit pass 1 set for itself. | Retitled to 57 characters. |
| P1 | 2 pages | `installing-mcp-servers` (159) and `hooks-patterns` (156) meta descriptions exceeded 155. Both came from the generator's own overrides table. | Rewritten to 149 and 144, in `sync-content.mjs` as well as the pages, so a regenerate cannot reintroduce them. |
| P2 | Module 06 overview | 67-character description that was a sentence fragment, not a summary. | Replaced with a 149-character summary, added to the overrides table. |
| P2 | Footer | `careerbeastmode.com` and `commanderinchief.ai` 308 to their `www` hosts, so both sister links cost a redirect hop. | Both point at the canonical `www` host. |

Verified after the fixes, against the built site in Chromium: 37/37 routes 200, 0 broken internal links (46 checked), 0 JSON-LD errors, 0 console errors, 0 title/description/canonical violations, no horizontal scroll at 390 px, `llms.txt` lists all 19 lessons and 6 overviews, sitemap `lastmod` genuinely git-derived (two distinct dates, neither the build date), and the homepage curriculum map matches the `modules/` tree exactly - 6 modules and 19 lessons in each README's own order. Light and dark captures of six routes at 390 and 1440 are pixel-identical, confirming the dark-only lock.

Not defects, checked and cleared: the "undefined" on the first-session page is deliberate teaching copy about a JavaScript bug; the second `<h1>` a naive HTML scan finds on the React patterns page lives inside a `data-code` copy-button attribute and never enters the DOM; the five-column table on `/cohort` is clipped at 390 px but scrolls inside its own box, and the page itself does not scroll horizontally.
