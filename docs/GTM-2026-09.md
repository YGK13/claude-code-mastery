# Claude Code Mastery: go-to-market plan, September 2026

Creator-led course GTM. The free curriculum is the top of funnel; the repo is the distribution object; The Leverage Brief is the retention channel; PortLev Academy programs are the paid tier.

## 1. ICP, jobs to be done, trigger events

**ICP A: executive operators** (primary for revenue). CHRO/VP People, RevOps leads, founders, consultants and fractional executives billing $300+/hour, 5 to 20 hours a week of automatable work, no engineer to delegate to, can read code but do not write it.
Job: "Ship two or three working AI tools into my own practice this quarter without hiring or learning to be a developer."
Triggers: a board or CEO asking "what is our AI plan"; watching a peer demo an agent; a Leverage Brief issue with a concrete build; a LinkedIn post showing a 60-second app; being told to cut headcount and keep output.

**ICP B: builders and developers** (primary for distribution). Engineers, technical founders and indie hackers adopting agentic coding.
Job: "Get the CLAUDE.md, hooks, permissions, MCP and multi-agent patterns that make Claude Code reliable, without reading forty blog posts."
Triggers: first week with Claude Code; a runaway session or a permissions scare; a teammate mentions MCP; searching "claude code hooks example".

ICP B stars, forks and shares. ICP A pays. The landing page now gives each a separate entry point (Module 01 vs Module 03).

## 2. Positioning and messaging hierarchy

One sentence: **Claude Code Mastery is the free, open-source, project-first curriculum that takes executives and builders from installing Claude Code to shipping web apps, AI agents, automations and MCP servers, written by a three-time CHRO who builds with it daily.**

Pillars:
1. **Project-first, sequenced.** Six modules, each ends with something deployed. Not a reference, not a playlist.
2. **Built for non-engineers, respected by engineers.** Module 01 starts at zero; Modules 03 to 06 carry the production patterns.
3. **Open and maintained.** MIT on GitHub, mirrored to the site by script, updated as the tool changes, new modules announced in The Leverage Brief.

Proof (all verifiable in the repo): 6 modules, 19 lessons, 4 reference guides, 4 templates, 2 runnable examples, ~20 hours; instructor credentials as stated in README.

Primary CTA: Start Module 01 (free). Secondary: Star on GitHub / Subscribe to The Leverage Brief. Tertiary: PortLev Academy programs.

Copy rules: no em dashes (spaced hyphen), no Oxford comma, no emoji in headings, "Claude Code" always with the independence line in footer and FAQ.

## 6. Growth loops and retention

- **Lesson -> video -> lesson.** Each lesson embeds its video; each video description links the lesson; both link the repo. Search intent enters on either side.
- **Star -> feed -> star.** GitHub stars surface the repo to followers of the starrer. The README asks for a star in exchange for early access to new modules (delivered via the Brief).
- **Brief -> build -> Brief.** Readers send what they built; the best builds become "Built with the curriculum" entries on the site and in the next issue.
- **Fork -> team -> cohort.** Companies fork the repo for internal training (MIT). The footer and FAQ point them to a facilitated version.
- Retention: the Brief (weekly), a "changelog" section on the site for tool updates, and a `lastUpdated` stamp on every page (git-driven) so returning readers see freshness.

## 9. Risks and mitigations

- **Trademark.** The name uses an Anthropic mark. Mitigated by the independence line in footer, FAQ and llms.txt; long-term, migrate the brand to a domain that does not use the mark (section 10) while keeping "Claude Code" in titles as the subject.
- **Tool drift.** Claude Code changes monthly. Mitigation: `lastUpdated` per page, a standing "check the official docs" note, one maintenance pass per month, community issues on GitHub.
- **Stale scarcity copy.** Removed hard-coded spot counts; all pricing/dates now live on learn.portlev.com and the site links there.
- **No analytics.** Until Vercel Web Analytics is enabled nothing here is measurable. Human to-do 1.
- **Domain authority is zero.** The `.vercel.app` host will rank slowly. Mitigation: subdomain of portlev.com (inherits authority) or a purchased domain with 301s from the current host.
